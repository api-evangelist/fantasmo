# Fantasmo

> Fantasmo builds CPS (Camera Positioning System), a computer-vision "camera-powered GPS replacement" that delivers hyper-accurate positioning indoors and in dense urban environments using only a device camera and a data connection. Target applications include micromobility, robotics navigation, mobile AR, and automotive lane-level positioning. Techstars-backed; acquired by Niantic in 2022. The public site remains online but exposes no developer portal, API reference, SDK, or OpenAPI surface.
